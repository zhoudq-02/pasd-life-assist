## C1 proof: bounded experience distillation

**Setup.** Let (f_1, f_2, …) be the episode-ordered failure sequence. The Extractor maps each
failure to a signature σ_t = (stage, error_code, conditions); the OnlineClusterer assigns σ_t a
cluster identity (stage, error_code, cluster_id) at radius r = 0.45; Gate1 deduplicates by
identity, so the library B_t holds at most one skill per identity. Hence

> |B_t| = number of distinct cluster identities observed up to episode t.

**Claim 1 (general boundedness — no purity needed).** If the signature space Σ is bounded, online
clustering at fixed radius r produces at most N(r) clusters, the r-packing number of Σ (finite for
bounded Σ). Therefore |B_t| ≤ N(r) for every t — the library is bounded independently of episode
count.

**Claim 2 (tight bound under purity 1).** Suppose failures are generated by exactly k latent
physical/interaction causes, and the clustering has purity 1: every cluster is contained in the
signature set of a single cause, and no cause is split across more than one cluster. Then |B_t| ≤ k.

*Proof.* (i) |B_t| = #clusters by Gate1 dedup. (ii) Purity 1 gives a well-defined map ψ from
clusters to causes. (iii) "No cause split" makes ψ injective. (iv) Hence #clusters ≤ #causes = k,
so |B_t| ≤ k for all t. ∎

**Relaxed form (purity p < 1).** When clusters mix causes, ψ is no longer injective and the tight
k-bound is lost; the general bound |B_t| ≤ N(r) (Claim 1) still holds. The ablation that removes
Gate1 (identity dedup) makes |B_t| grow linearly in t — one entry per failure — matching the
reproduced E1 observation (240 failures → 211 without dedup vs 9 with dedup).

**Convergence criterion.** B_t converges at episode τ if for N consecutive episodes (e.g. N = 20)
no new cluster identity is created and FTR is stable; then |B_t| = |B_τ| for all t ≥ τ.

# 05　参考文献勘误与术语（禁止使用的错误写法）

> 2026-11-10 已逐篇核对 9 篇 PASD 参考文献原文（题名、摘要、方法章节、实验表）。核对发生在打包端 Windows 机器，PDF 未随仓库分发，但全部结论已落在本文与 `docs/upstream/reference-corrections.md`，**Linux 目标机无需原始 PDF 即可使用本仓库**。PASD 构想文档的参考文献列表是「缩写 + 推测展开名」，9 篇里 8 篇的展开名或类别归属与原文不符，5 篇连展开名都错。
> **代码注释、变量名、日志、论文表格里一律使用下表「原文实际」列，不得沿用错误展开名。**

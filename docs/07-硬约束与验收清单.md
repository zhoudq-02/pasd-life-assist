# 07　硬约束、FTO 边界与验收清单

> 目标环境为 Linux，命令一律 `python3`。部署侧细则见 `docs/08`。

## 1　十条不可违背的实现约束

1. 五原语白名单；任何越界调用立即抛 `WhitelistViolation` 且不执行。
2. `get_observation()` 只返回 `REAL_OBSERVABLE_FIELDS`；禁仿真真值。
3. `split == "heldout"` 时 `run_episode` 不得调用 `on_episode_end`。
4. `MemoryPlugin` 是唯一读/写注入点；基线内不得自带执行循环。
5. `snapshot()` 六字段齐全，缺字段由 `fairness_audit.py` 判失败。
6. `promote()` 是唯一能改 `skill.state` 的函数；安全包络否决优先于 Gate2 达标。
7. Gate2 前先校验 `repair_plan.fixes == error_code`，不匹配直接拒绝。
8. 单臂不可自主修复模式（`IK_UNREACHABLE` / `GRASP_IMPOSSIBLE` / `INTENT_AMBIGUOUS`）返回 `None` 修复，不晋升。
9. `domain_rand.py` 只在离线训练阶段被调用，禁止在线部署链。
10. E3–E7 不预填数值；`--dry-run` 只打印协议，不产出"结果"。

## 3　安全与伦理

- 控制层外挂：速度/加速度限幅、工作空间盒、力矩上限、急停与 Watchdog，不依赖 LLM 生成代码自觉；Linux 侧由 `GuardedBackend` 落实（`docs/01` 第 9 节）。
- 真人实验前先用**假人头部模型 / 模拟口部位置**完成 E4 去 Gate3 消融。
- 论文须给出停机协议、最小人机距离阈值来源、用户同意与风险说明。
- 经验库持久化文件、真机日志、API 密钥一律不入库（见 `.gitignore`；`deploy/make_dist.py` 打包时二次排除）。
- 默认后端恒为 `mock`；真机需 `PASD_ALLOW_REAL` / `PASD_ESTOP_ACK` / CLI 显式确认三重条件（`docs/08` 第 6 节）。

## 5　诚实的边界（写进论文 Limitation）

- 结论基于所给 5 篇中文文献、9 篇原文、4 件专利截图，**未做外部专利库与文献库系统检索**。
- 截图仅含著录项目、摘要与主权项；A/B 状态依公开号后缀推断，需国知局登记簿核验。
- 「66 引用」疑为万方模板值，不作计量指标。
- VLA 端到端原生复现在本平台不可公平实现，是有效性威胁。
- 单臂、两任务、单用户；未覆盖多机器人协同与长期居家部署。
- Claude Code 生成 `repair_plan` 的质量直接影响 Gate2 通过率，构成外部效度边界。
- 仿真夹持力与摩擦标定是最大仿真不确定性来源，须真机「逐步降低夹持力直到滑落」标定 + SRCC 监测。
- `PiperSDKAdapter` 与 `MuJoCoBackend` 尚未在真机/仿真验证：前者需现场核对 SDK 的 6 项，后者需提供 PiPER MJCF 模型；二者当前均为**显式失败的适配器骨架**，不构成已完成的系统能力。
